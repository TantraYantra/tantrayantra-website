HOW TO INSTALL

Get DrishtiX running
in a few minutes.

1. Download

Click the Download DrishtiX (Windows) button above to get DrishtiX-Setup.exe (≈88 MB).

2. Run the installer

Double-click DrishtiX-Setup.exe to start the installation. It installs per-user — no admin rights needed.

3. Launch the app

DrishtiX appears in your Start Menu and on the Desktop. Open it and your library is ready.

IMPORTANT — WINDOWS SMARTSCREEN

Windows may block the installer
here's what to do.

DrishtiX is an independent, open-source project. The installer is not yet code-signed, so Windows SmartScreen may show a warning. This is expected and does not mean the file is unsafe.

If you see "Windows protected your PC"

  1. Click "More info" (or "More options") on the warning dialog.
  2. Click "Run anyway" at the bottom of the expanded screen.
  3. The installer will launch normally.

Verify the file hash (optional)

To confirm the installer hasn't been tampered with:

  1. Download SHA256SUMS.txt from the GitHub release page.
  2. Open PowerShell in your Downloads folder and run:
  3. Get-FileHash DrishtiX-Setup.exe -Algorithm SHA256
  4. Compare the result to the hash in SHA256SUMS.txt. They should match.
HOW TO USE

Your photos, your way
a quick start guide.

1. Add your photos

Open DrishtiX and use the scan function to import photos from any folder on your computer. Your original files are never moved or deleted.

2. Faces are grouped automatically

On-device face recognition detects and groups faces into profiles. You can name each person and confirm or merge matches.

3. Everything stays local

All processing happens on your computer. No photos, face data, or settings leave your device. No account, no cloud, no telemetry.

4. Your library lives here

%LOCALAPPDATA%\TantraYantra\DrishtiX\

Your database, settings, and cached model files are stored in this folder. You can back it up or move it like any other folder.

PRIVACY

Your data stays yours
always.

DrishtiX does not collect, store, or transmit any personal data. All photos, face data, and settings remain on your local device. The only network request is a one-time download of AI model files (verified by SHA-256 checksum). No telemetry. No account. No cloud sync.
